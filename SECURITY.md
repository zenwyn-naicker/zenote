# Security

Zenote runs on your Mac and has no accounts or servers. Your PDFs and chats stay in `~/Library/Application Support/Zenote`, and the AI runs locally through Ollama.

## Reporting a problem

Please don't open a public issue for a security problem. Use **Report a vulnerability** on this repository's Security tab, and include the steps to reproduce it.

This is a personal project, so fixes are made on a best-effort basis. Only the latest release is supported.
